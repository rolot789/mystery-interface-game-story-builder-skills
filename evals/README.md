# 스킬 행동 평가

`scenarios.json`은 스킬이 지시대로 행동하는지 보는 시나리오 묶음이다. 자동 테스트는 스킬 코드가 맞는지를 보고, 이 평가는 **모델이 스킬을 읽고 올바르게 행동하는지**를 본다. 예를 들어 모순을 알리는지, 사용자 대신 확정하지 않는지, 근거 없는 설정을 만들지 않는지를 확인한다.

## 시나리오 형식

| 필드 | 의미 |
|---|---|
| id | 시나리오 이름 |
| skills | 이 시나리오가 시험하는 스킬 |
| fixture | 대화 시작 시점의 Canon snapshot |
| prompt | 사용자가 보내는 메시지 |
| expect | 응답에 있어야 하는 행동. 하나씩 통과·실패를 채점한다 |
| avoid | 응답에 있으면 안 되는 행동. 하나라도 있으면 시나리오 실패다 |
| ground_truth | 선택. 프롬프트대로 바꾸면 검사기가 잡아야 하는 규칙 ID |

`ground_truth`는 `tests/test_evals.py`가 매번 확인한다. fixture에 patch를 적용했을 때 rules의 규칙이 실제로 나오고, 적용 전에는 나오지 않아야 한다. rules가 비어 있으면 patch 결과에 오류가 없어야 한다. 검사기나 fixture가 바뀌어 평가 기준이 어긋나면 CI가 실패한다.

## 실행 방법

1. 이 저장소의 6개 스킬을 함께 설치한 환경에서 새 대화를 연다.
2. 시나리오의 fixture를 현재 프로젝트 snapshot으로 제공한다. 로컬 파일로 두거나 대화에 첨부한다.
3. prompt를 그대로 보낸다. 모델이 질문하면 가장 중립적인 답(“추천대로”, “네”)을 하되 결정을 대신 내려 주지 않는다.
4. 응답과 모델이 만든 snapshot 변경안을 보고 expect와 avoid를 채점한다.
5. snapshot 변경안이 있으면 `python3 skills/notion-canon-manager/scripts/canon.py validate`로 실제 규칙 결과를 확인한다.

## 채점 기록

시나리오마다 한 줄씩 남긴다. 스킬 문서를 고친 뒤 같은 시나리오를 다시 돌려 비교한다.

| 날짜 | 모델 | 시나리오 | expect 통과 | avoid 위반 | 메모 |
|---|---|---|---|---|---|
| | | retention-shortened | 3/4 | 없음 | 대안을 1개만 제시 |

- 한 번의 통과로 결론 내리지 않는다. 같은 시나리오를 여러 번 돌려 통과율을 본다.
- 실패한 expect는 해당 스킬 문서의 어느 지시가 약했는지와 함께 기록한다.

## 시나리오 추가

- 실제 기획 중에 모델이 실수한 순간을 시나리오로 만든다.
- 검사기가 잡을 수 있는 실수면 ground_truth를 붙인다.
- 새 fixture가 필요하면 `tests/fixtures`에 작은 세계로 추가한다. 실제 사용자의 게임 데이터는 넣지 않는다.
