# 검토 기준

## 검사 항목

각 검사는 자동 규칙이 잡는 부분과 사람이 판단할 부분으로 나뉜다. 자동 규칙 목록 전체는 `notion-canon-manager`의 `references/data-contract.md` 규칙 목록을 따른다.

| 검사 | 자동 규칙 | 직접 확인할 내용 |
|---|---|---|
| 시간·인과 | TIME-001, TIME-002, TIME-003, TIME-006, GRAPH-001 | 선행 조건이 실제로 원인인가. 시각이 null인 객체의 순서가 서술과 맞는가 |
| 장소 | SPACE-001, SPACE-002, SPACE-003 | 장소가 없는 사건의 위치 서술, 일과(routine)와 사건 위치의 차이에 이유가 있는가 |
| 지식 | TIME-004, CLAIM-001 | 작성·행동 시점 이전에 해당 정보를 얻을 경로가 있는가. 기록 개요에 작성자가 몰랐던 내용이 섞였는가 |
| 정체성·관계 | TIME-007 | 동일 인물의 식별과 관계가 시점별로 일관되는가. 말투(voice)가 기록마다 일관되는가 |
| 시스템 | TIME-005, DATA-001, DATA-002 | 인증·보존·삭제·관리자 권한이 기록과 접근을 허용하는가. 필요한 접근이 권한 표에 있는가 |
| 명칭 | TERM-001, TERM-002 | 경고가 인물의 의도한 오칭인지, 설정 표류인지 |
| 세계 자립성 | WORLD-001, WORLD-002, WORLD-003, WORLD-004 | 사건 밖의 운영·문화·사용자 가치·생활이 성립하는가 (world-review 10항목) |
| 근거 | — | 결론을 지지·반박하는 관계에 추론 설명이 있고 대안 해석을 고려하는가. 같은 원본을 전재한 기록을 독립 근거로 세지 않았는가 |
| 조사·공정성 | FAIR-001 | 주요 정보가 해답 전에 발견 가능한가. 단일 우연·불가능한 접근·마지막 문서 한 장에만 의존하지 않는가 |
| 반전 | — | 이미 본 정보의 재해석에 근거가 있고 조기 노출 문제가 없는가 |
| 결말 | (validate의 witness 검사) | 같은 과거 진상에서 선택이 결과를 만들며 각 조건에 도달할 수 있는가 |
| 변경 | (impact) | 수정된 객체의 직접·간접 의존 항목이 모두 재검토됐는가 |
| 프로젝트 | (교차 프로젝트 검사) | 다른 게임·버전의 설정이나 ID가 유입되지 않았는가 |

## 심각도

BLOCKER: 핵심 사건이나 필수 결말이 성립하지 않음, 과거 진상 모순, 핵심 정보 경로 불가능. MAJOR: 중요한 인과·동기·근거가 부족하나 설계 수정으로 해결 가능. MINOR: 주변 표기·세부 설명 문제.

자동 규칙의 ERROR는 대상이 얼마나 핵심인지로 심각도를 정한다.

| 상황 | 심각도 |
|---|---|
| ERROR 대상이 핵심 Fact·Ending이 기대는 Event·Trace이거나 depth=CORE 설정 | BLOCKER |
| ERROR 대상이 사건에 쓰이지만 대안 기록·경로가 있는 설정 | MAJOR |
| ERROR 대상이 SUPPORTING·MENTION 설정이고 사건과 무관 | MINOR |
| WARNING이 실제 문제로 확인됨 | 영향에 따라 MAJOR 또는 MINOR |

## 이슈 기록

이슈에는 title, severity, affected_ids, evidence, violated_rule, suggested_fix, status를 기록한다.

- validate의 findings는 규칙 ID와 대상 ID를 가진다. violated_rule과 affected_ids에 그대로 적는다.
- 의미 검토에서 나온 이슈는 violated_rule에 검토 항목 이름을 적는다(예: "근거", "world-review 3 돈의 흐름").
- 자동 검사 결과와 의미 검토 결과를 별도 evidence로 남긴다.
- 수정 후 해당 이슈와 영향 범위를 재검토한다.
- 이관(MIGRATION) 이슈는 사용자와 확인한 뒤 닫는다.

## 한계

구조 검증은 ID·참조·상태·조건·대표 도달 경로와 규칙 목록의 고정점 관계를 검사한다. 자연어 진실성, 심리적 개연성, 실제 플레이 재미를 증명하지 않는다. 주요 미정이 남으면 ‘완성’ 대신 ‘초안, 다음 결정 필요’로 보고한다.
