# 기획 완료 기준

- 플레이어의 위치·조사 동기·인터페이스가 설명된다.
- 과거의 주요 원인·행동·결과가 시간선으로 이어진다.
- 인물의 행동이 해당 시점의 정보와 욕구로 설명된다.
- 세계 헌장의 현실 거리·핵심 전제·조사 현재 시점이 확정되었다.
- 정한 세계 범위의 주요 조직·서비스는 일상 운영·문화·재원·예외 처리를 가진다. CORE 세계 설정은 구조화 필드(연표 시각, 장소 계층, 보존·권한·기록 유형)를 갖는다.
- 게임에 나오는 기록 유형마다 서비스의 기록 규칙(보존, 삭제 흔적, 권한)이 정해졌다.
- 사건이 이용한 허점과 PLOT_NEED 설정마다 세계 안의 근거가 있다.
- 해답에 필요한 사실과 규칙이 해답 전에 볼 수 있는 기록으로 드러난다.
- 주요 진상에 도달할 기록과 추론 경로의 개요가 있다.
- 서로 의미가 다른 두 개 이상 결말에 실제 가능한 선택 경로가 있다.
- 모든 결말은 동일한 과거 진상을 참조한다.
- BLOCKER 이슈와 핵심 구조를 바꾸는 미정이 남아 있지 않다. 구조화 snapshot이 있으면 `canon.py validate --complete`에 ERROR가 없고, WARNING은 검토되어 이슈로 만들었거나 의도로 기록되었다.
- 기획서의 사용자 결정과 제안이 구별되며 연결한 Canon 리비전이 기록된다.
- Notion 저장 완료와 로컬 초안 완료를 구별한다.

인물·도시·조직 수나 질문 총량을 모든 프로젝트에 강제하지 않는다. 조건을 만족하면 최종 기획서를 제시하고 실제 재미·난이도의 플레이 검증은 별도임을 필요한 만큼만 설명한다.
