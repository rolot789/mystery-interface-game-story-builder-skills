# 밀도·공개도·출처 기준

모든 설정을 같은 깊이로 쓰면 세계는 끝없이 커지고, 얕게 쓰면 주변부에서 모순이 생긴다. 설정마다 밀도, 공개도, 출처를 붙여 **어디까지 써야 충분한지**를 정한다.

## 밀도

| 밀도 | 기준 | 서술 분량 |
|---|---|---|
| CORE | 사건, 핵심 기록, 선택과 결말에 직접 관여한다 | 해당 층 문서의 모든 항목 |
| SUPPORTING | 사건에 직접 관여하지 않지만 CORE를 설명하거나 생활을 채운다 | 아래 필수 항목 + 필요한 만큼 |
| MENTION | 이름이나 한 줄로만 등장한다 | 아래 필수 항목만 |

새 설정은 SUPPORTING으로 시작한다. 사건과 연결되면 CORE로 올리고, 해당 층 문서의 빠진 항목을 채운다.

## 밀도별 필수 항목

**고정점은 밀도와 관계없이 필수다.** 밀도가 낮아도 모순은 생기기 때문이다.

| 종류 | MENTION | SUPPORTING (MENTION에 추가) |
|---|---|---|
| 모두 공통 | 용어집 표기, 공개도, 출처 | 존재 시기(연표) |
| 장소 | 상위 장소 | 출입 조건, 주요 연결의 이동 시간, 생활 리듬 한 줄 |
| 조직 | 존재 목적 한 줄 | 재원, 평범한 업무, 관계 기관 |
| 서비스 | 제공자, 사용 이유 한 줄 | 게임에 나오는 매체의 보존 기간과 권한 |
| 규칙 | 내용, 적용 범위 | 강도, 집행자, 예외 |

## 공개도

PUBLIC / INSIDER / SECRET 중 하나를 붙인다. 판단이 어려우면 "주민 열 명에게 물으면 몇 명이 아는가?"로 판단한다. 대부분이면 PUBLIC, 특정 집단만이면 INSIDER, 거의 없으면 SECRET이다.

공개도는 플레이어 출발 지식, 인물의 말투, 공정성 판단에 쓰인다. SECRET 설정이 해답에 쓰이면 해답 전에 이를 드러내는 기록이 있어야 한다.

## 출처

| 출처 | 의미 | 추가 의무 |
|---|---|---|
| FOUNDATION | 세계를 설계하며 사건과 독립적으로 정한 설정 | 없음 |
| PLOT_NEED | 사건을 성립시키려고 추가한 설정 | 세계 내 근거, 사건 외 다른 결과, 플레이어 사전 노출 경로 |

PLOT_NEED는 나쁜 것이 아니다. 숨기지 말고 표시해서 검토받게 하는 것이 목적이다.

## 암묵 설정 회수

서술을 쓴 뒤 다음을 뽑는다.

- 새 고유명사(인명, 지명, 상호, 제품명)
- 수치(인원, 층수, 금액, 거리, 기간)
- 날짜와 시각, 요일
- 관계(누가 누구의 상사, 친척, 전 직장 동료)
- 규칙처럼 읽히는 문장("이 건물은 밤 10시에 잠긴다")

각 항목을 다음 중 하나로 처리한다.

1. 기존 고정점과 같으면 그대로 둔다.
2. 새 고정점이 필요하면 PROPOSED로 등록한다.
3. 필요 없으면 모호한 표현으로 되돌린다("몇 층짜리 건물", "오래된 동료").

기존 고정점과 다르면 서술을 고친다. 고정점을 바꾸려면 변경안으로 따로 제시한다.
