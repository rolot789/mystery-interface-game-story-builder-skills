# W2 제도: 규칙·조직·권력 지도

## 규칙(WorldRule)

규칙마다 유형과 강도를 정한다.

| 유형 | 예 |
|---|---|
| PHYSICAL | 지형, 기후, (INVENTED에서) 물리 법칙 |
| TECHNICAL | 시스템이 할 수 있는 일과 없는 일 |
| LEGAL | 법, 규정, 계약 |
| ORGANIZATIONAL | 조직 내부 규정과 절차 |
| SOCIAL_NORM | 관습, 예절, 금기 |
| ECONOMIC | 가격, 비용 구조, 시장 관행 |
| BELIEF | 사람들이 참이라고 믿는 것. 실제로 참인지와 별개 |

강도는 HARD(Canon 안에서 절대 깨지지 않음)와 SOFT(깨질 수 있지만 대가가 따름)로 나눈다. 사건이 규칙을 어긴다면 그 규칙은 SOFT이거나, 예외 조건이 서술되어 있어야 한다.

규칙마다 다음을 적는다.

- **내용과 적용 범위.** 누구에게, 어디에서, 언제부터 언제까지 적용되나. 유효 시점은 연표와 맞춘다.
- **한계.** 이 규칙으로 할 수 없는 것.
- **집행자와 위반 대가.** 누가 감시하고, 어기면 무엇이 일어나나. 집행자가 없는 규칙은 BELIEF 또는 SOCIAL_NORM이다.
- **비용.** 이 규칙을 유지하는 데 드는 비용과 부담하는 쪽.
- **예외.** 공식 예외와 비공식 관행상 예외를 구분한다.
- **근거.** 현실 근거(URL과 확인일) 또는 fictional 표시.
- **2차 파급.** 이 규칙이 참이면 반드시 존재할 것. HARD 규칙은 두 개 이상을 적거나, 없는 이유를 적는다.

## 조직(Organization)

부서 이름을 나열하지 말고, 부서들이 서로 무엇을 요구하고, 숨기고, 의존하는지 설명한다. CORE 조직은 다음을 모두 갖는다.

| 항목 | 질문 |
|---|---|
| 존재 목적 | 왜 존재하나. 공식 사명과 실제로 하는 일이 다른가 |
| 재원·사업 모델 | 돈은 어디서 들어오고 어디로 나가나. W1 경제 흐름과 맞나 |
| 구조와 의사결정 | 누가 무엇을 승인하나. 결재선과 실제 영향력은 같은가 |
| 평가와 보상 | 구성원은 무엇으로 평가받나. 그 지표가 어떤 행동을 부추기나 |
| 공식 규정과 실제 관행 | 규정과 현장의 차이, 그 차이로 이득을 보는 사람 |
| 내부 갈등 | 부서 간, 세대 간, 노선 간 갈등 |
| 평범한 업무 | 사건이 없는 날의 일과 |
| 평판 | 외부(언론, 사용자, 규제기관, 경쟁자)가 보는 모습 |
| 역사 | 설립 시기와 현재 문화를 만든 과거 사건(연표 연결) |
| 관계 기관 | 상위·하위·경쟁·협력 조직과 서로에 대한 의존 |

평가 지표와 실제 관행은 인물 동기의 원천이다. "성과 지표 때문에 기록을 늦게 올리는 관행"처럼 제도가 행동을 만드는 연결을 찾는다.

비밀 조직도 운영 수단(돈, 사람, 장소, 연락 방법)과 외부 접점을 갖는다. 접점이 없는 비밀 조직은 존재할 수 없다.

## 권력 지도

미스터리에서 권력은 곧 기록을 다룰 수 있는 능력이다. 다음을 표로 정리한다.

- 누가 기록을 만들고, 고치고, 지울 수 있나.
- 누가 그것을 감시하나. 감시자는 누가 감시하나.
- 감시가 비는 시간과 경로는 무엇인가. 그 공백은 왜 존재하나(비용, 신뢰, 관행, 최근 개편).

감시 공백은 W5 허점 목록의 후보다. 사건에 쓰지 않는 공백도 세계의 현실감을 만든다.

## 완료 조건

- CORE 조직이 위 표의 항목을 모두 갖는다. SUPPORTING 조직은 [밀도 기준](depth-tiers.md)의 필수 항목을 갖는다.
- 사건과 기록에 관여하는 규칙이 유형, 강도, 집행자, 예외를 갖는다.
- 권력 지도에서 핵심 기록의 생성·수정·삭제 권한과 감시자가 정해졌다.
