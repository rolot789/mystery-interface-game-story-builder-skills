# 세계 설계 계약

## 범위

게임마다 새 세계다. 일반 설계 템플릿만 재사용하고 다른 게임의 기관·역사·인물 설정은 자동 복사하지 않는다. 현재 프로젝트에서 완성할 생활권과 주요 조직·서비스를 명시한다. 사건 밖 운영도 필수이며, 주변 지역·기관까지 무한히 확장할 필요는 없다.

## WorldRule

규칙 설명, 적용 범위·유효 시점, 예외, 허구/현실 근거, 행동에 미치는 영향을 적는다. 현실 제도에 의존하면 현재의 공식 자료를 조회하고 URL과 확인일을 기록한다. 가상의 제도에는 fictional 표시를 한다. 조사되지 않은 현실 법률·의학을 확정 사실로 쓰지 않는다.

## Organization

존재 목적, 재원·사업 모델, 외부 평판, 부서·의사결정, 평가·보상, 실제 관행, 내부 갈등, 평범한 업무, 역사와 관계 기관을 기록한다. 부서 이름만 나열하지 말고 서로 무엇을 요구하고 숨기거나 의존하는지 설명한다.

## Service

제공자·사용자·사용 이유, 정상 이용 과정, 인증·복구·권한, 생성·수정·삭제·복원·보존, 로그·알림, 동기화·오프라인, 지원·관리자 접근·실패를 검토한다. 실제로 해당 기능이 없으면 해당 없음과 이유를 남긴다. 존재하지 않는 기능을 모든 서비스에 강제하지 않는다.

## 자립성 검토

사건을 제거해도 일상 운영과 사용자 가치가 설명되는가? 조직 문화가 행동과 의사결정에 실제 영향을 주는가? 비용·권한·데이터 흐름이 서로 모순되지 않는가? 비밀 조직도 운영 수단과 외부 접점이 있는가? 세계의 부조리는 허용하지만 의도한 부조리와 우연한 설정 오류를 구별한다.
