# W3 정보 환경: 서비스와 기록 의미론

휴대폰·문서·검색·메신저형 미스터리에서 플레이어가 보는 모든 화면은 어떤 서비스가 남긴 기록이다. 기록이 **존재하는지, 언제 생겼는지, 누가 볼 수 있는지, 무엇이 지워졌고 무엇이 흔적으로 남는지**가 곧 퍼즐이다. 이 층의 규칙이 흐리면 가장 많은 모순이 생긴다.

## 서비스 프로필

서비스마다 다음을 검토한다. 실제로 해당 기능이 없으면 "해당 없음"과 이유를 남긴다. 존재하지 않는 기능을 모든 서비스에 강제하지 않는다.

| 항목 | 질문 |
|---|---|
| 제공자·사용자·사용 이유 | 누가 운영하고 누가 왜 쓰나. 사건이 없어도 쓸 이유가 있나 |
| 정상 이용 과정 | 가입부터 일상 사용까지 |
| 출시와 변경 이력 | 언제 출시됐고 어떤 기능이 언제 바뀌었나. 연표에 올린다 |
| 인증·복구 | 로그인 수단, 2단계 인증, 계정 복구 경로, 공유 기기 |
| 권한 | 역할별 읽기·수정·삭제·복원·내보내기 |
| 데이터 수명 | 생성·수정·삭제·복원·보존 기간, 만료 후 처리 |
| 로그·알림 | 무엇이 로그로 남고 누가 보나. 알림 미리보기에 무엇이 뜨나 |
| 동기화·오프라인 | 기기 간 동기화, 오프라인 작성, 충돌 처리 |
| 지원·관리자 접근 | 고객 지원이 볼 수 있는 것, 관리자 열람과 감사 로그 |
| 실패 | 장애, 버그, 데이터 유실. 실패는 기록 공백의 정당한 원인이다 |

## 매체별 필수 질문

게임 UI에 등장하는 매체는 아래 항목을 모두 정한다.

| 매체 | 반드시 정할 것 |
|---|---|
| 메신저 | 타임스탬프 기준(기기·서버·시간대), 읽음·전달 표시(단체방 포함), 수정 표시, 삭제 후 남는 흔적("삭제된 메시지"), 보존 기간, 백업, 기기 동기화, 알림 미리보기 |
| 메일 | 발신·수신 시각 차이, 전달·참조 기록, 첨부 보존, 휴지통 보존 기간, 예약 발송, 관리자 열람 |
| 문서 | 버전 기록, 작성자·수정자 메타데이터, 공유 권한 변경 이력, 오프라인 편집 충돌, 댓글 삭제 흔적 |
| 검색 | 색인 지연, 캐시·스냅샷, 자동완성과 검색 기록, 삭제 요청 반영 속도 |
| 사진·파일 | 촬영 시각·위치 메타데이터, 클라우드 동기화 시각, 편집 이력, 휴지통 |
| 통화·위치 | 통화 기록 보존, 부재중 표시, 위치 기록의 정밀도와 갱신 주기 |
| 계정 | 로그인 기록, 새 기기 알림, 비밀번호 변경 알림, 세션 만료 |

## 기록 형식

schema v1에서는 Service 텍스트 필드에 다음 형식으로 한 줄씩 쓴다.

```
보존: 메시지 | 30일 | 영구 삭제 | 법적 보존 요청 시 1년
보존: 삭제된 메시지 표시 | 영구 | 해당 없음 | 없음
권한: 방 관리자 | 단체방 메시지 | 읽기·삭제 | 방 설정에서 허용한 경우
권한: 고객 지원 | 신고된 메시지 | 읽기 | 신고 접수 후 14일
```

## 흔한 모순 함정

- **삭제했는데 남은 것.** 메시지를 지웠어도 알림 미리보기, 상대 기기, 백업, 인용 답장, 검색 캐시에 남을 수 있다. 무엇이 남는지 정하지 않으면 플레이어가 "왜 여기엔 남아 있지?"라고 묻게 된다.
- **시각의 기준.** 기기 시각과 서버 시각, 작성 시각과 전송 시각, 시간대가 다르면 같은 사건의 기록이 서로 다른 시각을 보인다. 의도한 차이인지 기록한다.
- **보존 기간과 조사 현재 시점.** 조사 현재 시점에 이미 만료된 기록은 존재할 수 없다. 존재한다면 예외(백업, 법적 보존, 버그)가 설정되어 있어야 한다.
- **출시 전 기록.** 서비스나 기능이 출시되기 전 시각의 기록을 쓰지 않는다.
- **관리자 만능 해결.** 필요한 기록 접근을 임의의 관리자 권한으로 해결하지 않는다. 권한 표에 없는 접근이면 규칙을 먼저 바꾸고 파급을 검토한다.
- **편집 흔적.** 수정 이력이 남는 서비스라면, 수정된 기록에는 이력이 함께 있어야 한다.

## 완료 조건

- 게임에 등장하는 모든 기록 유형이 어떤 서비스의 매체 규칙으로 설명된다.
- 사건에 쓰이는 기록마다 보존 기간과 조사 현재 시점이 양립한다.
- 핵심 기록의 접근 경로가 권한 표 안에 있다.
